- 电话对话、电话选择流程（当前dialogue工具明确phone_dialogue_supported=false）。
- 原生history超过100条后的无损追溯、跨进程/所有存档持久化、WebSocket实时推送。本版按用户选择使用原生录音机，无独立补录/网络推送系统。
- 长按交互（仅原生铃铛明确无需长按时可click），不绕过确认时间。
- 道具选择待用、指定目标使用/消费、装备目标点击与完整取消状态机。
- 液体倾倒/定量转移、化学多成分与特殊容器完整支持。
- 自动堆叠、向已有物品/容器投放、递归找空间、库存自动整理、批量拆卸机器。
- 窗口拖动、世界相机移动、复杂手绘UI/小游戏和所有剧情分支。
- 完整的保存退出/重启再载入、禁用/卸载、云同步验收。
